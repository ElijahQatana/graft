# Configuration

Graft does not expose its full configuration yet. The current settings tab is a placeholder and persists an empty settings object.

The planned settings cover:

- Google and Outlook or Microsoft 365 ICS feed URLs
- note folders and templates
- title and ignore-list filters
- sync-window and preview behavior
- Person and Series stub creation

Calendar feeds remain read-only. Keep private feed URLs and real calendar data out of source files, fixtures, issues, and logs.
